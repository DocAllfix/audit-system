# Prompt Checklist per Norma

Questa cartella contiene i prompt specifici per ogni norma.
Quando l'utente seleziona una norma nella Tab 2, verrà caricato il prompt corrispondente.

## File da Caricare

Carica qui i tuoi 6 prompt (formato Word o MD):

- `ISO_9001.docx` o `ISO_9001.md`
- `ISO_14001.docx` o `ISO_14001.md`
- `ISO_45001.docx` o `ISO_45001.md`
- `ISO_37001.docx` o `ISO_37001.md`
- `SA_8000.docx` o `SA_8000.md`
- `PAS_24000.docx` o `PAS_24000.md`

## Note

- I prompt verranno analizzati e adattati per produrre output JSON
- Mantieni i nomi file con underscore (es. ISO_9001 non ISO 9001)
