# Template Checklist Word

Questa cartella contiene i template Word con placeholder per la compilazione automatica.
La Tab 3 (Compila Checklist) userà questi file per generare la checklist finale.

## File da Caricare

Carica qui i tuoi template Word mappati:

- `checklist_ISO9001.docx`
- `checklist_ISO14001.docx`
- `checklist_ISO45001.docx`
- `checklist_ISO37001.docx`
- `checklist_SA8000.docx`
- `checklist_PAS24000.docx`

## Note

- I template devono contenere placeholder come {{AZIENDA}}, {{DATA_AUDIT}}, etc.
- La struttura delle tabelle deve corrispondere ai campi del JSON
